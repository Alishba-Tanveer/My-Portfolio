Read before you rely on this panel

This admin panel is a front-end demo: the password check and the data you see here live entirely in this browser's localStorage, not on a server. That means it's fine for previewing the idea locally, but it is not secure. Anyone with browser dev tools can bypass the password, and messages don't sync between devices or visitors. A real password-protected admin panel needs a backend (an API with proper authentication, like the Node.js + JWT setup used in Shopsie) and a database to store submissions in. Say the word if you'd like help planning that next.
