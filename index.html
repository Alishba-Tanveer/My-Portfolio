How I work

Three things I hold onto on every project

One codebase, both platforms

Shared logic between web and mobile where it makes sense, so features don't have to be rebuilt twice.

The database comes first

A schema that models the real problem prevents most of the bugs that show up later in the UI.

Ship it, then watch it

A feature isn't done at merge — it's done once it's live and behaving the way real users need it to.
