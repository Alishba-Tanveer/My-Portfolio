Shopsie (An In-person Shopping Helper App)

Online shopping solved a lot of problems, but not the ones people still run into at a physical shop: which one nearby actually has what you need, whether the price is fair, and how you're getting a full cart home without a car. Shopsie was my answer: a mobile app that treats a shopping trip like a route to be planned, not a guess to be made.

The problem

Shoppers waste time visiting stores that don't have what they need, with no easy way to compare prices across nearby shops or get help carrying purchases home.

The approach

Four connected roles (Customer, Shopkeeper, Rider, Admin) each with a purpose-built flow, sharing one backend and one source of truth for inventory, pricing, and location.

How each role uses it

Customer

Builds a shopping list, discovers nearby shops carrying those items, and compares prices before heading out.

Shopkeeper

Manages product listings and inventory so what's shown to customers matches what's actually on the shelf.

Rider

Assists customers with physical purchases and helps get them and their shopping where they need to go.

Mobile app

Built with React Native, JavaScript, Expo and Expo Router. Maps and route planning run through Leaflet, embedded via WebView.

Backend

Node.js and Express.js serving REST APIs, JWT authentication, Multer for file uploads, and Prisma ORM connected to MySQL.
